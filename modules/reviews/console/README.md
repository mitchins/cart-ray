# Reviews moderation console (test only)

A small, independent staff surface for the existing Reviews pending queue and approval/rejection endpoints. It is not deployed or enabled by installing Reviews. To test, serve this directory under an authenticated, same-origin test gateway that forwards `/reviews-admin/v1/` to the Reviews Worker in explicit test collection mode and injects a verified staff assertion at the trusted gateway. The gateway must protect the HTML and API with the same independently authenticated staff policy. No assertion, administrator token or secret is entered into or stored by the page. Do not expose this experimental UI publicly or use it with production data.

The API currently provides a subject reference rather than an approved product name in pending results. Published-review lists, withdrawal controls, staff replies, revision/audit browsing and delivery reconciliation require additional authenticated backend endpoints and are intentionally not represented as functioning controls. The Access-only purchase-mode prerequisite, live identity-provider qualification, deployment policy and operator permissions remain gates. This console is a first vertical slice, not a complete merchant product.
